# TMIXTOOL

混音时间参考工具。替代两个老工具：**梦逍遥音频基准时间小助手**（音符时值、效果器时间、混响与预延迟参考）和 **MixMeister BPM Analyzer**（速度检测），并新增**调性检测**与**调音检测**。

拖入一个音频文件，几秒内给出：

- **速度** —— 主导 BPM、半速/倍速备选、置信度
- **调性** —— 大调/小调、候选与置信度
- **调音** —— 参考音高（如 A = 443.1 Hz，+12 音分）
- **延迟** —— 5 组立体声配对（含附点八分等经典设置）
- **压缩起始 / 释放** —— 按实际会用的毫秒值给，附使用场景说明
- **混响衰减 / 预延迟** —— 音符时值档位；预延迟覆盖 Haas 阈值两侧

音符时值不单列一张表——延迟表和混响表里每一项都带着音符名与对应毫秒值，单列反而是重复。

---

## 使用

**绿色便携版**：`dist/TMIXTOOL/` 整个目录拷走即可，双击 `TMIXTOOL.exe`。不需要装 Qt，也不需要 Visual C++ 运行库。

- 拖入文件，或点按钮选择；也支持"用 TMIXTOOL 打开"
- **不拖文件也能用**：在底部直接输入速度，立刻得到全部时值与效果器参考
- 右上角 `EN` / `中文` 切换语言
- 底部可手动输入 BPM，所有表格立即重算；`恢复检测值` 退回算法结果

**命令行版**（`TMIXCLI.exe`，同一目录）适合批处理和脚本：

```powershell
.\TMIXCLI.exe "歌曲.mp3"           # 完整报告
.\TMIXCLI.exe "歌曲.mp3" --quiet   # 只输出一个 BPM 数字
```

## 关于速度检测

半拍与双拍在数学上是**真歧义**：等间距的脉冲串的谐波结构让它与两倍速同样自洽，这不是实现缺陷。所以本工具不去猜，而是：

1. 搜索在 60–200 的宽范围内照常进行，如实报告找到的值
2. 结果**按八度折叠**进"偏好范围"（默认 60–180）
3. 折叠发生时界面上明确写出原始搜索结果

对细分音符密集的素材（踩镲铺满八分音符的 boombap 等），搜索常给出 180 而实际拍速是 90，折叠就是为这种情况准备的。

## 关于调音检测

每个谱峰为"自己离最近半音的偏离量"投票，音准一致的音符聚成一簇，簇心即为参考音高。实测精度**优于 2.4 音分**，足以分辨 A=440 与 A=441（相差 3.9 音分）。

色谱图不够集中时（纯打击乐、重度噪声）不输出，而不是编一个数字。

## 构建

需要 MSVC 2022、CMake + Ninja、Qt 6.8。路径在 `build.bat` 里，按需修改。

```powershell
.\build.bat                                     # 构建
.\build\src\tests\TMIXTests.exe                 # 跑全部测试
cd build; ctest --output-on-failure             # 或走 CTest
powershell -File scripts\package.ps1            # 生成便携目录
python tools\make_icon.py                       # 重新生成图标
```

## 结构

```text
src/core/     纯 C++17 分析核心，零 Qt 依赖 —— 因此能用命令行和测试独立验证
src/cli/      TMIXCLI
src/gui/      Qt/QML 界面（FluentWinUI3 样式，自绘卡片）
src/tests/    测试与合成信号 fixture
tools/        离线辅助脚本
```

`src/core` 不依赖 Qt 是刻意的：准确率必须在做界面之前就能验证。GUI 只做展示，所有数值计算都在核心层完成。

## 图标与关于对话框

`.exe` 的文件图标、窗口与任务栏图标来自 `src/gui/assets/tmixtool.ico`，由 `tools/make_icon.py` 生成（比例、配色、圆角都在脚本顶部，改一行重跑即可）。

图标是**几何绘制的 T**，配色取自项目原画采样出的墨色 `#6C2E3E`。没有直接把那张线稿做成图标，是因为实测过它做不到：线稿元素密度太高，五种裁切、四档二值化+粗化、十二个网格区域、三种对比度处理在 32 像素下全部退化为噪点。

**原画放在关于对话框里**（右上角"关于"按钮）——那里是大尺寸静态展示，细节从劣势变成了本钱。

## 测试

78 个用例、约 2800 处断言，全部基于**有已知真值的合成信号**（已知 BPM 的节拍轨、已知调性的和弦、已知失谐量的音高、半拍/双拍陷阱信号）。fixture 用固定种子，结果可复现。

```powershell
.\build\src\tests\TMIXTests.exe            # 全部
.\build\src\tests\TMIXTests.exe Tempo      # 按名字过滤
```

设置 `TMIX_DEBUG_TEMPO=1` 或 `TMIX_DEBUG_KEY=1` 可以打印候选打分与色谱图，用于排查判断依据。

## 已知限制

- 速度检测在细分音符响亮的素材上会倾向于偏快，靠偏好范围折叠纠正；偏好范围目前写死在 `TempoConfig`（默认 60–180），无法在界面上调整
- 调性是整曲单一调性，不处理中途转调
- 调性检测在**没有低音声部**的声部配置下会倾向关系小调（例如裸的 C-E-G 三音可能报 E minor）。有低音的常规编曲不受影响
- 调音检测依赖稳定音高内容，纯打击乐素材上不输出
- 尚未实现：波形与节拍网格、节拍点击试听、设置界面
